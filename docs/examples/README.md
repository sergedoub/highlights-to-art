# Selected generation examples

These two images were intentionally selected by the project owner for the public README. They were generated through built-in OpenAI ImageGen on September 27, 2026, using an earlier prompt. They are not examples of verified physical Kindle display, and are not represented as outputs of the final default prompt.

- `wind-and-words.png`: quotation from *All the Pretty Horses* by Cormac McCarthy. The illustration interprets the highlighted sentence; the torn canvas and arrangement of the scene are generated elaborations.
- `ministry-of-peace.png`: quotation from *1984* by George Orwell. The architecture and dove/tank arrangement are conceptual imagery, not a canonical scene illustration.

The code and reusable prompt templates are MIT licensed. The literary quotations are credited to their authors and are not relicensed under the code license. The images are AI-generated interpretations, not scans or reproductions of a book's published artwork.
